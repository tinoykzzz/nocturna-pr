# Cliente Total Estado Fecha

Agregar producto

Creá una nueva prenda con nombre, precio, categoría, imágenes (subida a Storage o URL) y stock inicial. El formulario es el mismo que en Catálogo → Nuevo producto.

  • Subí la foto principal y la galería al bucket de Supabase desde el mismo formulario.
  • Marcá Producto nuevo si querés destacarlo en la tienda.
  • Tras guardar, el producto aparece en Catálogo y en la web si las políticas RLS lo permiten.

Ajustar inventario (stock)

Actualizá unidades sin abrir el formulario completo. Indicá el stock final y guardá por producto.

Importación masiva de stock (CSV)

Formato: primera fila id,stock (o id;cantidad con Excel regional). El id es el UUID del producto en Supabase (copialo desde Table Editor → products).
